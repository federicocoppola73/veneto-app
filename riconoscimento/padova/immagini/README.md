# Foto di riferimento – Padova

Aggiungere qui una sottocartella per ciascun ID luogo, ad esempio:

```
immagini/
  basilica-di-sant-antonio/
    01.jpg
    02.jpg
    03.jpg
```

Dopo aver caricato le foto, riportare i relativi percorsi in `../indice.json`, nel campo `immagini` del luogo corrispondente.
