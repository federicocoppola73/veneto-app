# chiesa-di-san-canziano

Carica qui le fotografie di riferimento di questo luogo.

I nomi dei file possono essere scelti liberamente (es. `facciata-principale.jpg`, `vista-laterale-01.webp`). Quando le immagini saranno caricate, aggiungi i relativi percorsi nell'array `immagini` del luogo con ID `chiesa-di-san-canziano` in `riconoscimento/padova/indice.json`.
